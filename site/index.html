ফাইল ও Form প্রস্তুতির নিয়ম

সঠিক workbook ও prefilled link দিলে mapping সহজ হবে।

01

ফাইলের ধরন ও গঠন

.xlsx, .xls বা .xlsm workbook ব্যবহার করুন। প্রথম row-তে প্রতিটি column-এর header রাখুন; একেকটি data row হবে একটি review link। ফাঁকা row বাদ যাবে।

02

Worksheet বাছাই

একাধিক sheet থাকলে upload-এর পর সঠিক worksheet বাছুন। Merged header বা header-এর ওপর title row থাকলে আগে workbook-এ ঠিক করে নিন।

03

সঠিক Google Forms link

Google Form-এর menu থেকে Get pre-filled link নিন, sample value দিন, তারপর generated link paste করুন। সাধারণ forms.gle share link-এ field ID থাকে না।

04

Column mapping

প্রতিটি entry ID-কে workbook-এর সঠিক column-এর সঙ্গে মেলান। কোনো field পাঠাতে না চাইলে সেটি ফাঁকা রাখুন; সব link generate হওয়ার আগে mapping দেখে নিন।

05

তথ্য ও submission

Workbook browser-এ process হয়, server-এ upload হয় না। Link/CSV-তে ব্যক্তিগত তথ্য থাকতে পারে, তাই সাবধানে রাখুন। প্রতিটি link খুলে যাচাই করে Google Form-এ নিজে submit করুন।

Excel পড়ার library internet থেকে load হয়। তাই workbook local থাকলেও page খোলার সময় internet দরকার।
